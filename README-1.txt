README - Controls

Canvas / Eye / Look at / Up / Window boxes
Set the canvas size and camera, then press Render to ray cast again.
Pre-filled with the assignment defaults.

Shadows checkbox
Turns shadows on/off. On by default.

Triangles checkbox (Part 5)
Off by default, so Render alone reproduces Part 4 (lit ellipsoids +
shadows, no triangles). Check it and press Render to also draw the
Part 5 triangle in the same scene.

Render button
Re-reads all the controls above and ray casts the scene again.

Make it your own button (Part 6)
Plays a short animation: the Poke Ball starts closed, opens from the
back to 45 degrees (band and button move with the top half), the
light inside brightens to a whiteout, then an image is shown. The
space bar does the same thing as clicking this button.
